## Цель и структура данных

Создать реляционную схему для заявок, заполнить её учебными данными и выполнить запросы фильтрации, сортировки, соединения и группировки.

- `network_sites` — справочник участков сети.
- `users` — диспетчеры и электромонтёры.
- `cable_tickets` — заявки, связанные внешними ключами с участком, автором и (опционально) исполнителем.

У таблиц есть первичные ключи; ограничения `UNIQUE` защищают логины, названия участков и номера заявок. Внешние ключи запрещают ссылки на отсутствующие записи. Ограничения `CHECK` валидируют роли, допустимую длину темы и описания и статусы `New`, `InProgress`, `Closed`, `Cancelled`. Индексы созданы по статусу, участку и внешним ключам.

## Файлы лабораторной

- `db/schema.sql` — создание таблиц, связей, ограничений и индексов.
- `db/seed.sql` — два участка, два пользователя и четыре заявки с разными статусами; повторный запуск обновляет записи с теми же ID.
- `db/queries.sql` — запросы для фильтра, сортировки, JOIN и GROUP BY.

## Выполненные запросы

Фактические результаты запросов из `db/queries.sql`:

```text
Фильтр WHERE status = 'New': КБ-201

Сортировка ORDER BY created_at DESC:
КБ-204, КБ-203, КБ-202, КБ-201

JOIN с network_sites:
КБ-201 | Москва — Замоскворечье
КБ-202 | Северный участок — Север-3
КБ-203 | Москва — Замоскворечье
КБ-204 | Северный участок — Север-3

GROUP BY status:
Cancelled | 1
Closed    | 1
InProgress| 1
New       | 1
```

## Проверка PostgreSQL

Скрипты проверены на PostgreSQL 18.6 в базе `course_tickets`. `schema.sql` выполнен два раза подряд — таблицы пересозданы без ошибок. `seed.sql` выполнен два раза — повторная загрузка не создала дубликаты. Контрольная вставка со статусом `Done` была отклонена PostgreSQL ограничением `cable_tickets_status_check`:

```text
ERROR:  new row for relation "cable_tickets" violates check constraint "cable_tickets_status_check"
```

В последующей ЛР10 таблицы приложения были созданы EF-миграцией, а демонстрационные строки повторно загружены через `seed.sql`. Команды и проверка фактического результата миграции описаны в `docs/reports/lab-10.md`.
