Заявка на тему лабораторных работ

Название и организация

Название: Учет состояния сети с прогнозированием потенциальных проблем  
Организация: АО «Компания ТрансТелеКом»

2. Главная сущность и справочник

- Главная сущность: Заявка на повреждение кабеля
- Справочник: Участок сети (`siteId` — числовой идентификатор)

3. Роли и права

| Роль | Создаёт заявку | Назначает исполнителя | Меняет свой статус | Видит все заявки |
|------|:---:|:---:|:---:|:---:|
| Диспетчер сетей | да | да | нет | да |
| Электромонтёр | нет | нет | да | нет (только свои) |

4. Сценарий в одно предложение

Диспетчер создаёт заявку на повреждение кабеля, назначает электромонтёра, электромонтёр проводит работу по устранению неполадки и закрывает после устранения.

6. Что не входит в семестр

- Прогнозирование потенциальных проблем (ML, предиктивная аналитика).
- Интеграция с Zabbix / системами мониторинга в реальном времени.
- Мобильное приложение для монтажников.
- Карта сети с визуализацией повреждений.
- Печать актов и отчётов.
- Оплата, договоры, СМС-уведомления.
- Синхронизация с 1С и другими внешними системами.

7. Запас под ВКР (4+ пункта)

1. Данные/процесс: Привязать конкретный кабель и наряд-допуск.
2. Связь с другими системами: Интеграция с GIS-картой сети.
3. Аналитика: Выгрузка сводки начальнику службы.
4. Прогнозирование: Добавить ML-модель для предсказания повреждений.

8. Чем не копия соседа

- Другая организация — оператор связи, а не ЖКХ/поликлиника/склад.
- Другой главный объект — инцидент по кабелю, а не заявка на сантехнику.
- Другая специфика справочника — кабельный участок с городом, длиной, типом кабеля.
- Разные роли — диспетчер, монтажник, начальник смены (не «админ/пользователь»).
