# Архитектура системы

## Схема из трёх узлов

Vue 3 + Vite              ASP.NET Core              PostgreSQL
localhost:5173  ────────► localhost:5000  ────────► обычно :5432
                    HTTP                      запросы к БД
              POST /api/cable-tickets

**Это и есть архитектура web-ИС семестра.** Три узла, две связи,
один источник правды о заявках на повреждение кабеля.

## Пояснения

| Кто | Порт | Что делает |
|---|---|---|
| Vue-клиент (ЛР3) | 5173 | Рисует экраны, шлёт HTTP-запросы |
| ASP.NET Core | 5000 | Проверяет правила, отвечает |
| PostgreSQL | 5432 | Хранит строки таблиц |

- Стрелки только: клиент → сервер, сервер → база.
- Прямой стрелки «браузер → PostgreSQL» нет: иначе клиент
  получил бы доступ к данным и обошёл серверные правила.
- Вся правда о заявках лежит на сервере, поэтому два
  диспетчера видят одно и то же.
